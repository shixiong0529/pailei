## 结论与严重程度

每个检查项只输出五种结论之一：

| 结论 | 含义 |
|---|---|
| 发现风险 | 触发高风险阈值或检索到高风险类公告 |
| 需要关注 | 信号存在但未达风险级，或属需人工判断的事项 |
| 已覆盖资料中未发现明显异常 | 基于已获取资料未触发阈值；不代表绝对安全 |
| 数据不足，无法判断 | 缺少必需科目或公告清单，明确标注而非估算 |
| 不适用 | 该检查对本公司口径无经济含义（如净利息收入公司的利息保障倍数） |

严重程度（高/中/低）与证据强度分别表达，二者独立。

## 通用约定

- **重要性过滤**：应收账款、存货占总资产 < 2% 时，其增速类指标不形成结论（小基数增速无经济意义）
- **同比口径**：严格上一年同期（中报对中报），要求币种、范围、单位与期间一致；负利润基数时普通同比返回"数据不足"并说明
- **期间口径**：季度、中报、三季报和年报分别标记；A 股指标接口未提供期次代码时按报告日识别，五年覆盖只统计完整年报
- **可用现金**：货币资金扣除受限资金后再参与覆盖类计算，缺失不可当零；港股单列现金及等价物不再次扣除受限现金
- **金融行业排除**：银行、保险、券商的"负债"即经营对象，普通企业财务结构规则对其不适用（表中"排除"列）
- **行业包路由**：按行业分类关键词匹配（银行/保险/券商/地产），无法判定时归入 general；
  特殊行业在行业包之外仍执行财务质量、治理、监管类通用规则

## 通用规则（36 项）

### 财务质量 FQ（12 项）

| ID | 名称 | 判定逻辑与阈值 | 排除 |
|---|---|---|---|
| FQ01 | 利润与经营现金流背离 | 净利润为正时，经营现金流/净利润 < 0 → 风险(高)；< 0.5 → 关注(中)；净利润为负时倍数不适用，零或缺失时无法计算 | — |
| FQ02 | 经营现金流为负 | 经营活动现金流净额 < 0 → 风险(高) | — |
| FQ03 | 应收账款增速快于收入 | 应收同比 − 收入同比 > 30pp → 风险(中)；> 10pp → 关注(低)；应收/总资产 < 2% 不形成结论 | 金融 |
| FQ04 | 应收账款占收入比重过高 | 应收/收入 > 60% → 关注(中) | 金融 |
| FQ05 | 存货增速快于收入 | 存货同比 − 收入同比 > 30pp → 风险(中)；> 10pp → 关注(低)；存货/总资产 < 2% 不形成结论 | 金融 |
| FQ06 | 非经常性损益依赖 | 非经常损益/净利润 > 50% → 风险(中)；> 30% → 关注(中) | — |
| FQ07 | 扣非净利润为负 | 扣非 < 0 且净利 ≥ 0 → 风险(高)（靠非经常项目扭亏）；扣非 < 0 → 关注(中) | — |
| FQ08 | 报告期净利润为负 | 净利润 < 0 → 风险(高) | — |
| FQ09 | 营业收入大幅下滑 | 收入同比 < −30% → 风险(中)；< −10% → 关注(低) | — |
| FQ10 | 净利润大幅下滑 | 净利同比 < −50% → 风险(中)；< −20% → 关注(低)；负基数时返回数据不足 | — |
| FQ11 | 销售收现比偏低 | 销售商品收到现金/收入 < 0.8 → 关注(中) | 金融 |
| FQ12 | 财务重述或追溯调整 | 检索"更正/追溯/差错"类公告，命中 → 风险(中) | — |

## 行业包（16 项）

行业包按公司行业分类关键词路由启用；监管口径指标（资本充足率、偿付能力等）在
当前数据源未提供时一律输出"数据不足"，不做估算。

|---|---|---|

## 误报治理记录

以下误报已修复并有单元测试回归保护（详见 DEVELOPMENT_STATUS.md 第二节）：

1. 财务费用为负时利息保障倍数无意义 → SV04 先判符号
2. 半年报固定勾选项命中"保留意见"关键词 → OP02 断言式匹配 + 模板排除 + 否定词识别 + 区间去重
3. 续聘公告被当成审计机构变更 → GV01 区分变更词与例行词
4. 小基数存货/应收增速误报 → FQ03/FQ05 重要性门槛
5. 港股例行文件被误分类为高管变动 → 披露易分类器先识别例行文件
6. 行业包启用导致通用规则全部跳过 → packs 白名单改为 exclude_packs 排除制
